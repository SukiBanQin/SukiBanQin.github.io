ZBrush｜基础操作与模型管理

适用版本：ZBrush 2023.1.1 中文版（默认 UI）。笔刷、Alpha 和部分插件在中文版里仍可能显示英文资源名，因此采用“中文作用 + 英文搜索名”。由坂琴写完粗稿然后交给ChatGPT优化。粗搞位于👉学习建模所记录的一些笔记 | 坂琴的小窝🍜

在游戏 PBR 管线中的职责

ZBrush 主要负责高模的形体塑造与可烘焙细节。游戏公司验收高模时，更关注轮廓、结构层级、材质语言、部件关系和能否稳定投射到低模，而不是单纯追求面数。UV、低模预算和引擎性能仍由后续环节负责。

从基础网格到可交付高模：详细流程

A. 接收与备份

  1. 从 3ds Max 导出基础网格前，检查比例、轴向、法线、开口、重面和部件划分。
  2. 导入后先另存一份 ZTL/ZPR，再开始改变拓扑；基础网格和正式雕刻文件分开保存。
  3. 确认每个可独立移动或需要独立烘焙的部件是否应为单独 子工具 / SubTool。
  4. 使用可读名称，例如 body_high、bolt_high；不要长期保留 PM3D_Sphere3D_1 之类默认名。

B. 选择几何密度方案

需求 优先方法 原因与风险
保留干净拓扑并逐级雕刻 工具 / Tool → 几何体 / Geometry → 细分 / Divide 有低级别可回退，适合可控硬表面和角色流程。
快速合并形体、概念雕刻 动态网格 / DynaMesh 会重新生成拓扑；原 UV、边流或细分级别可能无法保留。
已完成雕刻但拓扑不适合继续细分 重新拓扑后投射细节 适合建立干净生产拓扑，但必须检查投射误差。

先用能支撑大形的最低密度工作，只有当前顶点不足以表现下一层细节时才提高密度。原笔记的 130–150 万面只是某次课程参考，不是阶段目标。

C. 按层级雕刻

  1. **大形：**轮廓、比例、重量、主要平面和部件穿插；不断缩小模型检查剪影。
  2. **中形：**结构转折、接缝、破损块面、主要褶皱和工艺特征。
  3. **小形：**表面纹理、毛孔、细裂纹和轻微噪声；必须服务于材质，不能平均撒满。
  4. 每完成一个层级，换多个角度和中性 MatCap/材质检查；不要让强阴影替代真实形体。
  5. 硬表面边缘不能无限锋利，也不能圆得像融化；倒角尺度要能在烘焙分辨率和最终观察距离中被法线读到。

D. 组织与可逆修改

  1. 子工具按资产结构命名、排序和分组；用多边形组表达需要局部隐藏、分组或拆分的区域。
  2. 关键阶段递增保存；高风险 DynaMesh、合并、删除低级别或减面前先复制子工具。
  3. 需要局部试改时可先存储 变形目标 / Morph Target，再用变形笔刷恢复；它不能代替版本备份。
  4. 保留清晰的“设计面”和“自然破损”区分。木头、石头等材料可以不规则，但不能因此破坏装配关系和主要轮廓。

E. 烘焙交付

  1. 删除误留的测试工具，隐藏不需要导出的子工具；检查名称与低模 _low/_high 匹配。
  2. 确保高模与低模仍处于同一坐标、比例和姿态。
  3. 过重高模可以在副本上减面，但要检查轮廓、倒角和细节是否损失；保留未减面的源 ZTL。
  4. 导出后在空场景重新导入，确认子工具数量、名称、单位、正反面和部件位置。
  5. 在 Toolbag/Painter 做一次低质量测试法线；若波浪来自高模平面或倒角，回 ZBrush 修形，不要只修 Cage。

1. 初次启动与显示设置

原笔记的启动调整：

  1. 文档 / Document → 双倍 / Double。
  2. 文档 / Document → 背景渐变范围 / Range 设为 0。
  3. 点击右上角横杠，收起或展开界面托盘。
  4. 左侧颜色渐变设为纯白，材质选择 BasicMaterial。
  5. 确认后用 文档 / Document → 另存为启动文档 / Save As Startup Doc 保存为启动文档。

2. 自定义 UI

保存自己的布局

  1. 打开 首选项 / Preferences → 配置 / Config → 启用自定义 / Enable Customize。
  2. 按住 Ctrl + Alt 将按钮拖到需要的位置。
  3. 调整完后关闭“启用自定义 / Enable Customize”。
  4. 使用“保存 UI / Save UI”另存布局；需要加载别人的布局时使用“加载 UI / Load UI”。
  5. 确认界面稳定后点击“存储配置 / Store Config”，让下次启动继续使用。

UI 配置文件通常是 CFG。保存前建议保留一份默认布局，避免找不到关键面板。

老师的 UI

首选项 / Preferences → 界面 / Interface → UI 按钮大小 / UI Button Size 从默认 48 改为 41。

3. 从 3ds Max 准备雕刻模型

正确理解“面数不够”

之前笔记写“模型面数不够不能导入 ZBrush”，这不准确：

  • ZBrush 可以导入低多边形网格。
  • 低模只是没有足够顶点承载雕刻细节；导入后可以用“工具 / Tool → 几何体 / Geometry → 细分 / Divide”或“动态网格 / DynaMesh”等方式提高密度。
  • 保留低级别有利于大形调整、烘焙和导出。

✅ 修正：“不能导入”改为“可以导入，但雕刻前通常需要增加可雕刻的几何密度”。

样条线与网格

原始样条线通常不能直接作为 OBJ 网格雕刻。导出前应转换为可编辑网格/多边形，并检查：

  • 是否有开口、重合点或非流形结构；
  • 法线方向是否正确；
  • 各部件是否需要分开成为子工具 / SubTools；
  • 是否保留低模基础拓扑。

OBJ 导出建议

  1. 在 3ds Max 中整理需要雕刻的对象。
  2. 导出 OBJ，预设可选择 ZBrush。
  3. 不需要材质时关闭“导出材质 / Export Materials”和“创建材质库 / Create Material Library”。
  4. 不必无条件在 Max 中加 4–5 级 TurboSmooth。
  5. 若确实在 Max 中细分，先估算结果面数；每次四边面细分大约会变成原来的 4 倍。

✅ 修正：之前笔记“面数能高就高”容易造成性能问题。更好的原则是“从可控低模开始，逐级增加到足够支撑当前细节”。

4. 导入模型与子工具 / SubTool 管理

导入

  • “工具 / Tool → 导入 / Import”可以导入 OBJ 等网格。
  • 导入行为会受当前“工具 / Tool”“多边形网格 3D / PolyMesh3D”和“导入 / Import”选项影响；在某些情况下会替换当前网格。
  • 导入前先保存，确认当前选中的工具和子工具，避免误覆盖。
  • 需要导入多个独立部件时，优先使用明确的“追加 / Append”“插入 / Insert”或“Multi Append”工作流，而不是依赖“随便插一个再替换”的记忆技巧。

插入 / Insert 与追加 / Append

命令 原笔记中的理解
插入 / Insert 在当前选中的子工具下方插入。
追加 / Append 追加到子工具列表末尾。

删除子工具需要使用 工具 / Tool → 子工具 / SubTool → 删除 / Delete。键盘 Delete 通常不是删除整个子工具的安全方式。

进入可编辑状态

  1. 在“工具 / Tool”中选中模型。
  2. 在画布拖出模型。
  3. 点击顶部“编辑对象 / Edit”，或按 T 进入 3D 编辑模式。

若没有进入“编辑对象 / Edit”，继续拖动只会在 2.5D 画布上复制快照，这也是新手常见的“模型突然铺满画布”。

5. ZTL、ZPR 与文档 / Document

类型 保存内容 适合场景
ZTL / Z 工具 / ZTool 当前工具，以及它的全部子工具、细分级别、图层等工具数据 日常保存单个资产，通常体积较小。
ZPR / Z 项目 / ZProject 更完整的项目：多个工具、相机、画布/背景、材质与其他场景设置 需要完整恢复项目环境时。
文档 / Document 2.5D 画布内容 插画式 Pixol 工作，不等于保存可继续雕刻的 3D 模型。

保存与打开

  • ZTL：工具 / Tool → 另存为 / Save As；原笔记记录快捷键为 Ctrl + Shift + T。
  • 打开 ZTL：工具 / Tool → 载入工具 / Load Tool。
  • ZPR：文件 / File → 另存为 / Save As；打开时用 文件 / File → 打开 / Open。
  • 采用递增命名，例如 asset_001.ztl、asset_002.ztl，不要只留一个覆盖版本。

✅ 修正：ZTL 不是“只保存一个子工具”，而是保存所选 Z 工具及其全部子工具。ZPR 也不应被理解为自动保存到原 OBJ 所在目录；“另存为”时应明确选择路径。

6. 从 ZBrush 导出

当前工具 / Tool 与子工具 / SubTool

“工具 / Tool → 导出 / Export”用于导出当前工具的网格，具体范围需结合 ZBrush 2023.1.1 的设置确认。

多个可见子工具导出 OBJ

原笔记路径：

Z 插件 / ZPlugin → 子工具大师 / SubTool Master → 导出 / Multi Export

导出前确认可见性、比例、Group/文件命名和是否需要合并。

FBX 导出

原笔记路径：

Z 插件 / ZPlugin → FBX 导出与导入 / FBX ExportImport → 导出 / Export

FBX 插件通常可以选择导出范围，不要默认认为一定会把“全部内容”无差别导出。正式交付前重新导入到空场景检查。

7. 视口导航与变换

基本导航

操作 鼠标/快捷键 说明
平移 Alt + 鼠标左键拖动；或右键导航方式 左键操作通常要从模型外区域开始，右键导航更容易跨过模型表面。
旋转 在模型外拖动鼠标左键；或使用右键导航 直接在模型上左键会雕刻，不应笼统写成“左键旋转”。
转正/吸附视角 旋转时按 Shift 吸附到主要轴向。
缩放 平移过程中松开 Alt、保持鼠标按下继续上下拖；或 Ctrl + 鼠标右键 先按 Alt 进入平移，再松 Alt 是常用手势。
聚焦 F 聚焦当前模型/选择。
线框显示 / PolyFrame Shift + F 显示线框与多边形组 / Polygroup 颜色。

雕刻与选择的补充快捷方式

操作 快捷方式 说明
打开笔刷选择 B 再按字母可继续缩小笔刷搜索范围。
调整笔刷大小 S 打开笔刷大小快速调节；自定义 UI 可能改变显示。
打开快速菜单 空格 可快速调笔刷大小、强度、焦点偏移等。
临时反转笔刷方向 按住 Alt 雕刻 常用于在凸起/凹陷方向间临时反转；个别笔刷行为可能不同。
更换局部可见性选择笔刷 按住 Ctrl + Shift，再点击笔刷缩略图 可选择矩形、套索等选择方式；不是单独按 Ctrl + Shift 就永久切换。

Gizmo/变换模式

快捷键 模式
Q Draw / 雕刻绘制
W Move / 移动
E Scale / 缩放
R Rotate / 旋转

Alt + 鼠标左键点击不同模型，常用于快速激活不同子工具 / SubTool。

8. 子工具 / SubTool 选择与顶点着色 / Polypaint 提醒

  • 未激活的子工具通常会变暗，变暗程度受“首选项 / Preferences”设置影响。
  • 子工具列表在默认 UI 中通常位于右侧“工具 / Tool”面板，自定义 UI 后位置可以改变。
  • 子工具行上的画笔/着色图标与“顶点着色 / Polypaint”显示有关，不应简单理解成“打开后模型就无法编辑”。
  • 如果模型无法雕刻，依次检查：是否在“编辑对象 / Edit”模式、是否为“多边形网格 3D / PolyMesh3D”、是否被遮罩、是否在合适细分级、当前笔刷强度，以及是否选错子工具。

✅ 修正：原笔记把 Polypaint 图标称为“绘画模式，关掉才能编辑”，这不是可靠的通用排查结论。

9. 撤销历史 / Undo History

原笔记观察到：激活子工具 A 后 Ctrl + Z 会回退 A 的操作；切换到 B 后，B 有自己的操作记录体验。这个规律适合用来理解“撤销与当前编辑对象相关”，但不要把它当作文件备份。

建议：

  • 雕刻关键阶段使用 ZTL 递增保存；
  • 不要只依赖撤销历史；
  • 保存 ZPR 时是否包含完整撤销历史会明显影响体积，应按版本设置确认。

10. 多边形组 / Polygroup 与拆分、合并

查看多边形组 / Polygroup

按 Shift + F 打开“线框显示 / PolyFrame”。不同颜色代表不同多边形组，不一定代表不同子工具。

按组拆分

  1. 打开 工具 / Tool → 子工具 / SubTool → 拆分 / Split。
  2. 使用“按组拆分 / Groups Split”，把可见的不同多边形组拆成多个子工具。
  3. 拆分前保存，因为子工具数量和命名会改变。

合并回来

  1. 选中目标子工具。
  2. 使用 工具 / Tool → 子工具 / SubTool → 合并 / Merge → 向下合并 / Merge Down。
  3. 检查合并后是否焊接、是否保留不同多边形组。

重新分组

  • 对可见且未遮罩的部分按 Ctrl + W，可以创建或更新多边形组。
  • 更准确地说，Ctrl + W 会对当前可见/遮罩状态应用分组逻辑；结果要用 Shift + F 检查。

11. 遮罩 / Mask

在 ZBrush 中，遮罩是把区域保护起来，不让后续雕刻或变形影响它。它与 Painter 中“黑透白不透”的蒙版显示逻辑不是同一套直觉。

常用遮罩操作

操作 快捷键
在模型上绘制遮罩 按住 Ctrl 绘制
反向擦除遮罩 Ctrl + Alt 绘制
用矩形/Alpha 遮罩 Ctrl，从模型外拖动
反转遮罩 Ctrl + 点击画布空白
清除遮罩 Ctrl + 在画布空白处拖动
模糊遮罩边缘 Ctrl + 点击模型上的遮罩
锐化遮罩边缘 Ctrl + Alt + 点击模型上的遮罩

遮罩边缘质量受模型密度影响；低面模型上的涂抹遮罩会比较锯齿。需要干净边界时，可以先利用多边形组、拓扑遮罩或提高合理的细分级别。

✅ 原笔记“连续点击是虚化/锐化”补全为：应点击模型上的遮罩区域；点击画布空白有反转遮罩等不同意义。

12. 局部可见性 / Partial Visibility：显示与隐藏

操作 快捷键/颜色
只显示框选区域 Ctrl + Shift 拖动，绿色选择框
隐藏框选区域 Ctrl + Shift 拖动过程中加入 Alt，红色选择框
显示全部 Ctrl + Shift + 点击画布空白
反转当前可见性 Ctrl + Shift 在画布空白拖动
只显示某个多边形组 模型全部可见时，Ctrl + Shift 点击该多边形组

原笔记用 Ctrl + Shift + A 扩展到同一个连通模型。这一项没有足够上下文，可能与当时的选择笔刷、“全部增长 / Grow All”或自定义键位有关。

实际拆分思路

如果从 3ds Max 导入的多个独立零件被合成了一个子工具：

  1. 用“局部可见性 / Visibility”工具只显示一个连通零件。
  2. Ctrl + W 给可见部分建立独立多边形组。
  3. 重复处理其他零件。
  4. 最后用“工具 → 子工具 → 拆分 → 按组拆分”拆成独立子工具。

如果 Max 里本来就已分好对象，并且导入流程保留了分组，就不需要重新做一遍。

13. 面数与动态网格 / DynaMesh

原笔记新增记录：如果当前几何密度不足，可以在 工具 / Tool → 几何体 / Geometry → 动态网格 / DynaMesh 中重新生成网格。

  • 课程参考值约为每个模型 130–150 万面，但这不是固定标准。
  • 动态网格会重新分布拓扑，适合概念雕刻和统一网格密度，不等于普通的“细分 / Divide”。
  • 分辨率越高，保留的细节越多，运算和内存压力也越大。
  • 执行前保留副本；如果模型有细分级别、UV 或需要保留的拓扑，先确认动态网格会造成什么影响。

Ctrl 拖动画布空白：先判断当前情境

  • 一般遮罩操作中，Ctrl + 在画布空白处拖动用于清除遮罩。
  • 当 动态网格 / DynaMesh 已启用、模型处于可编辑状态且遮罩已清除时，同一手势可触发重新动态网格。
  • 如果模型仍有遮罩，第一次拖动可能只是清遮罩；不要看到网格没变化就误以为功能失效。

✅ 修正：原笔记“多用 Ctrl + 鼠标左键在空白处重新布线”缺少 DynaMesh 前提。它不是通用重新布线命令，也不会生成适合动画或最终游戏低模的规则拓扑。

复习提示：只在现有顶点不足以承载当前细节时增加密度，不要把“达到 150 万面”当成目标本身。

14. 笔刷选择与常用修边笔刷

  • 按 B 打开“笔刷选择”弹窗。
  • 弹窗打开后，可以继续按字母缩小笔刷搜索范围。
  • 雕刻木头、石头等硬质破损表面时，原笔记常用：
    • 自适应修边 / TrimAdaptive；
    • 动态修边 / TrimDynamic。
  • 这类雕刻常搭配偏方形的“Alpha 笔刷形状”，原笔记举例为 Alpha 28，用于辅助做出块面和断裂感。
  • 两种笔刷都容易快速改变平面和边缘，使用时应从较低强度开始，并随时旋转模型检查轮廓。

这里的 Alpha 指控制笔刷形状或强度分布的灰度图，不是 Painter 输出贴图中的透明通道。笔刷和 Alpha 资源名通常以英文或编号显示，因此保留 TrimAdaptive、TrimDynamic 和 Alpha 28 方便在界面中搜索。

变形目标 / Morph Target：保存局部修改前的形态

  1. 在目标子工具和正确细分级别上，打开 工具 / Tool → 变形目标 / Morph Target。
  2. 点击 存储变形目标 / StoreMT（Store Morph Target）。
  3. 进行雕刻或形体调整。
  4. 选择 变形 / Morph 笔刷，在需要的位置涂抹，把该区域恢复到已存储状态。
  5. 若拓扑或顶点顺序已经改变，旧变形目标可能不能继续使用；DynaMesh、重拓扑或某些合并操作前应另存版本。

背面遮罩：避免薄片被同时雕刻

路径：笔刷 / Brush → 自动遮罩 / Auto Masking → 背面遮罩 / BackfaceMask。

  • 适合布料边、薄金属片、耳朵等正反面距离很近的模型。
  • 开启后优先作用于朝向笔刷的一面，减少笔刷穿透到背面。
  • 它是当前笔刷设置，换笔刷后要检查是否仍启用；厚模型或需要贯穿变形时不要机械开启。

腐木破损：按原笔记补全的可复现步骤

  1. 复制子工具并保存版本；先完成木块大形和主要断面。
  2. 按住 Ctrl 进入遮罩操作。需要矩形投射时，把描边从 徒手 / FreeHand 切换到 拖拽矩形 / DragRect。
  3. 在 Alpha 中导入自制黑白图；先在测试区域确认黑白对遮罩的影响方向。
  4. 把要处理的断面尽量转正朝向屏幕，减少投射形变。
  5. 将 焦点偏移 / Focal Shift 设为 -100，让遮罩边缘更硬。这个数值来自原练习，应按 Alpha 和目标破损调整。
  6. 按 Ctrl 从断面上拖出 Alpha 遮罩。需要自由减去区域时，按住 Ctrl 打开遮罩笔刷选择，将 MaskPen 改为 遮罩套索 / MaskLasso，再用 Ctrl + Alt 删减遮罩。
  7. Ctrl + 点击画布空白反转遮罩，让需要变形的区域处于未遮罩状态。
  8. 按 W 进入移动模式，把 Gizmo 枢轴放到当前断面/选区的合理位置，沿需要的轴向拉出或压入，形成第一层断裂高低差。
  9. 用 Ctrl + 在画布空白拖动清除遮罩；换不同 Alpha、位置、大小和旋转重复，但不要形成等间距图案。
  10. 用 TrimAdaptive、TrimDynamic 和方形 Alpha（原笔记示例 Alpha 28）打破规则边，补充中尺度块面。
  11. 旋转模型检查轮廓、背面和接缝；薄片先启用“背面遮罩”，避免正反面一起被压坏。
  12. 若需要用 DynaMesh 合并形体，先复制子工具，再启用 DynaMesh；清除遮罩后 Ctrl 拖动画布空白执行重建。

复习重点：破损先有受力方向和大块缺口，再有中等崩边，最后才是细裂纹。随机不等于平均噪声。

15. 快速保存 / QuickSave、自动保存与磁盘空间

原笔记写：“C 盘爆满导致不能自动保存，把模型关掉重新打开即可。”这个处理不完整。

正确排查：

  1. 立刻手动另存到有空间的磁盘，确认文件能打开。
  2. 释放系统盘空间，尤其是 ZBrushData/QuickSave 目录。
  3. 在“首选项 / Preferences → 快速保存 / QuickSave”中检查设置与保留数量。
  4. 有需要时修改快速保存 / QuickSave 路径到空间充足的磁盘。
  5. 重启只能重新初始化软件，不能替代释放空间。

⚠️ 磁盘不足时，不要继续依赖“自动保存 / AutoSave”；先做一份确认可读的手动保存。

高模交付阶段门

  • [ ] 比例、轮廓、装配关系和主要平面在低细节显示下成立。
  • [ ] 大、中、小细节层级清楚，没有用噪声掩盖形体问题。
  • [ ] 子工具和 Polygroup 命名可读，_high 与低模配对明确。
  • [ ] 没有误隐藏、重复或不应导出的测试子工具。
  • [ ] DynaMesh、合并和减面都在副本上执行，原始可编辑 ZTL/ZPR 已保留。
  • [ ] 高低模坐标、比例和姿态一致。
  • [ ] 减面后的高模没有破坏轮廓、倒角和需烘焙细节。
  • [ ] 已完成测试法线烘焙，关键平面没有明显波浪或投射穿帮。

16. 一分钟复习卡

  • 进入可编辑模型：拖出工具 → 按 T 进入“编辑对象”。
  • 聚焦：F；看多边形组：Shift + F。
  • ZTL 保存一个 Z 工具及全部子工具；ZPR 保存更完整项目。
  • 低模能导入，雕刻前再逐级细分。
  • Ctrl 遮罩；Ctrl + Shift 控制局部可见性。
  • Ctrl + W 重新分组，结果用“线框显示 / PolyFrame”检查。
  • 面数不够：先判断需要“细分 / Divide”还是重新拓扑的“动态网格 / DynaMesh”。
  • 按 B 打开笔刷选择；TrimAdaptive、TrimDynamic 常用于硬质修边效果。
  • 木头、石头的块面雕刻可尝试方形 Alpha，例如原笔记中的 Alpha 28。
  • 先存“变形目标 / Morph Target”，再用 Morph 笔刷局部恢复。
  • 薄片雕刻先检查“笔刷 → 自动遮罩 → 背面遮罩”。
  • Ctrl 拖动画布空白通常先清遮罩；已启用 DynaMesh 且无遮罩时才重建网格。
  • C 盘满时先释放空间或改“快速保存 / QuickSave”路径，不是只重启。
